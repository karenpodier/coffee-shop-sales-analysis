# Coffee Shop Order Management System

## Project Overview

This project uses Python to build a simple coffee shop order management system.

The program allows a customer to view a menu, place multiple orders, calculate the total bill, apply VAT, service charges and discounts, and generate a printed receipt. The project also includes a lucky draw feature using Python’s `random` module.

This was completed as a beginner-friendly Python project to practise core programming concepts in a practical business scenario.

## Tools Used

- Python
- Jupyter Notebook

## Objectives

The project focuses on building a working order system that can:

- Display a coffee shop menu
- Take customer orders using user input
- Store orders using lists, tuples and dictionaries
- Calculate subtotals, VAT, service charge and discounts
- Apply tiered discount logic
- Use randomisation for a lucky draw feature
- Print an itemised customer receipt

## Skills Demonstrated

- Python syntax
- Variables and data types
- Lists, tuples and dictionaries
- Conditional logic using `if`, `elif` and `else`
- Loops
- User input handling
- Basic error handling
- String formatting
- Calculations
- Using Python modules including `random` and `datetime`
